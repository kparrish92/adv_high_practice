# Advanced Mid → Advanced High

- `advanced_mid_to_high.html` starts directly on the first English prompt.
- `index.Rmd` is an editable landing page that links to the activity.
- Main lesson: 60 targets / 120 slides.
- Each clicked target receives exactly two unseen review contexts.
- No explanation or title slides are included.
- The sequence is fixed to preserve scaffolding from cohesion and time frames through hypothesis, argument, circumlocution, and repair.

## Practice subsets

The activity still opens directly on a trial. A compact control in the upper-right corner lets the instructor/student switch between:

- 10 items
- 20 items
- 30 items
- All items

Smaller practice sets use a random contiguous block from the fixed 60-target progression, so local grammatical/discourse scaffolding is preserved. `New set` draws another block of the selected size.
